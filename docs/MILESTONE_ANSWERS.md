# CS153 Project Milestone Draft Answers

## Q1 Project Title

Threadline: a closet and shopping management web app that helps users decide what to rewear, style, buy, waitlist, or skip.

## Q2 Project Track

Application / Product.

## Q3 Progress

I scaffolded a working full-stack web prototype with a polished responsive front-end and a small Node.js backend that persists closet and shopping data to a local JSON file. Current functionality includes adding closet items with photo upload or phone camera capture, viewing/filtering a closet inventory, logging wears, managing a shopping queue, and seeing simple cost-per-wear and closet-gap signals.

## Q4 Future Implementation

Next I plan to add outfit planning, stronger recommendation logic for whether a new purchase fills an actual closet gap, and a more robust photo flow with image cleanup or tagging. I also plan to improve the shopping workflow with links, budget constraints, purchase decisions, and a final demo dataset that shows how the app changes a user's buying behavior over time.

## Q5 Github Link

https://github.com/angelarmao/threadline

## Q6 Compute

For the milestone, no special compute is needed. The prototype runs locally as a Node.js web app and stores data in JSON. Later versions could use a hosted database and optional computer-vision APIs for automatic item tagging, but the core milestone can run on a laptop.
