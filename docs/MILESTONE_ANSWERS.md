# CS153 Project Milestone Draft Answers

## Q1 Project Title

Threadline: a closet memory and purchase tracking web app that helps users log daily outfits, track what they own, and remember what they or their friends bought.

## Q2 Project Track

Application / Product.

## Q3 Progress

I scaffolded a working full-stack web prototype with a cohesive responsive front-end and a small Node.js backend that persists data to a local JSON file. Current functionality includes daily outfit photo upload with prototype auto-recognition chips, closet item tracking, purchase/wishlist tracking, a visual closet board, and a lightweight friends feed demo.

## Q4 Future Implementation

Next I plan to make outfit recognition editable and more accurate, connect outfit logs to specific closet items, and expand purchase tracking into a receipt/history view. I also plan to test the friends feed carefully so the social layer feels useful for inspiration and accountability rather than noisy.

## Q5 Github Link

https://github.com/angelarmao/threadline

## Q6 Compute

For the milestone, no special compute is needed. The prototype runs locally as a Node.js web app and stores data in JSON. Later versions could use a hosted database and optional computer-vision APIs for automatic item tagging, but the current prototype can run on a laptop.
